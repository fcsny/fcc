# AI 写作工作台 · 手机版（安卓）

电脑版的完整移植，**文件格式完全一致**（`.aiwriter.json`），
手机上写一半，导出传到电脑接着写，反之亦然。

功能：**API 接入 + 人物卡 + 文章编辑 + 资料库 + 世界观与指令 + AI 生成**，全都有。

## 一、怎么拿到 APK（三选一）

### 方式 A：GitHub Actions 云编译（推荐，零门槛）

不用装任何东西，GitHub 的服务器免费帮你编译。

**第 1 步：把代码传到 GitHub**

1. 注册 GitHub 账号（[github.com](https://github.com)，免费）
2. 右上角「+」→「New repository」
3. 仓库名填 `aiwriter-mobile`，选 **Public**，勾选 **Add a README file**
4. 点「Create repository」
5. 在仓库页面点「Add file」→「Upload files」
6. 把本文件夹里**所有文件拖进去**（注意要包含隐藏的 `.github` 文件夹）

   > Windows 显示隐藏文件：文件夹选项 → 查看 → 勾选「显示隐藏的文件、文件夹和驱动器」
   >
   > 更简单的方法：把整个文件夹**打包成 zip 上传**，GitHub 支持拖拽 zip 后自动展开

7. 底部点「Commit changes」

**第 2 步：触发编译**

1. 进仓库 → 点上方 **Actions** 标签
2. 左侧点「编译安卓 APK」
3. 右侧点「Run workflow」→ 下拉框选 `debug` → 点绿色「Run workflow」

**第 3 步：下载 APK**

1. 约 **15~25 分钟**后，刷新页面，那个任务会变成绿色 ✓
2. 点进去 → 拉到最下面 **Artifacts** → 点 `aiwriter-apk-debug` 下载
3. 解压得到 `.apk` 文件

**第 4 步：装到手机**

- 用微信/QQ 把 apk 传到手机，点开安装
- 或用数据线拷到手机，用文件管理器点开安装
- 红米手机会提示「未知来源应用」，允许即可
  （路径：设置 → 应用设置 → 安装未知应用 → 选择你用的文件管理器 → 允许）

> **`debug` 和 `release` 的区别**：`debug` 能直接装，适合自用；
> `release` 需要签名才能装。第一次建议选 `debug`。

### 方式 B：自己电脑编译

需要 **Windows 的 WSL 或 Linux 虚拟机**（macOS 原生不支持）。

```bash
# 在 WSL / Ubuntu 里执行
sudo apt-get update
sudo apt-get install -y git zip unzip openjdk-11-jdk autoconf libtool \
  pkg-config zlib1g-dev libncurses5-dev cmake libffi-dev libssl-dev build-essential
pip3 install --upgrade buildozer cython
./build-local.sh
```

首次编译要下载约 **3GB** 的 Android SDK/NDK，耗时 **30~60 分钟**。

### 方式 C：只有源码

`main.py` + `core/` + `ui/` 就是全部。用 `buildozer android debug` 编译。

## 二、装好之后：三件事

### 1. 填 API（必做）

底部「**API**」→ 填三样 → 点「**测试连接**」：

| 字段 | 填什么 |
|---|---|
| Base URL | `https://api.deepseek.com/v1` |
| API Key | 你的密钥（deepseek.com 开放平台申请，新用户有免费额度） |
| 模型名称 | `deepseek-chat` |

### 2. 写东西

底部「**文章**」→ 直接敲字。**改动后 1.5 秒自动保存**，也可以点底部「保存」。

### 3. 让 AI 接着写

在「文章」页底部填一句指令（比如"写一场对峙"），点「**生成**」，
AI 写完会直接插到光标处。

想先看看 AI 到底读到了什么？去「项目」页能确认数据有没有真的喂进去。

## 三、和电脑版互导数据

这是手机版的核心价值：手机上记灵感，电脑上细写。

### 手机 → 电脑

1. 手机端：底部「**项目**」→「**导出 zip**」
2. 文件会存到：`内部存储/Documents/AI写作工作台/`
3. 用微信/QQ 发到电脑，或用数据线拷出来
4. 电脑端：「项目」→「**从 zip 导入**」

### 电脑 → 手机

1. 电脑端：「项目」→「**导出为 zip（含图片）**」
2. 把 zip 传到手机，放进 `内部存储/Documents/AI写作工作台/` 目录
3. 手机端：底部「**项目**」→「**导入 zip**」→ 选那个文件

> **带图片的导出会自动打成 zip**，不带图片就只导出单个 `.aiwriter.json`。
> 两种格式手机版和电脑版都认。

### 自动同步（进阶）

装个 **Syncthing** 或 **微力同步**，把两边的目录配成同一个同步文件夹，
就再也不用手动导了。

## 四、手机版和电脑版的差异

| | 电脑版 | 手机版 |
|---|---|---|
| 界面 | 左侧导航 + 右侧编辑 | 底部六个标签 |
| 人物卡切页 | 左侧列表点选 | **顶部横向滑动的卡片条** |
| 保存 | 每个面板右上角按钮 + Ctrl+S | 每个页面底部按钮 + 自动保存 |
| 生成入口 | 右侧常驻面板 | 文章页底部 |
| 切后台 | 关闭窗口时保存 | **切后台立即保存**（防被系统杀掉） |

**为什么手机版不显示参考图？**
安卓的相册权限与文件路径管理比较复杂，第一版先保证主体稳定。
**图片数据本身完整保留**——电脑版挂的图，手机版会随项目一起导出，不会丢。

**手机上没有的：**
- 参考图挂载与预览
- 章节排序（只能新建/删除）
- 资料库的召回测试
- 指令片段库

## 五、数据存在哪、安全吗

- **项目文件**：App 私有目录，卸载 App 才会清空
- **位置**：`/data/data/org.aiwriter.mobile/files/data/`
- **导出区**：`内部存储/Documents/AI写作工作台/`（微信/QQ 能访问）

内容**不上传任何服务器**，只在点「生成」时把上下文发给你的模型服务商。

> ⚠️ 红米手机如果开启了「自动清理后台」，长时间不用可能会清掉 App 进程。
> 切后台时程序会自动保存，但**重要内容记得点一次顶部「保存」**，
> 或者导出一份备份。

## 六、常见问题

**Q：装不上，提示"未知应用"？**
设置 → 应用设置 → 安装未知应用 → 允许你用的那个文件管理器/浏览器。

**Q：点生成没反应？**
先去「API」页点「测试连接」。没填 API Key 会直接提示，不会静默失败。

**Q：导出后在文件管理器里找不到？**
路径是 `内部存储/Documents/AI写作工作台/`。
用「文件管理」App → 内部存储 → Documents。

**Q：导入后内容没变？**
导入后项目会切换，但当前页面可能还显示旧内容。
来回切一下底部标签，或重启 App。

**Q：会不会耗很多流量？**
只有点「生成」时才联网。一次长篇续写大概几十 KB。

## 七、开发者

```bash
# 逻辑测试（用 Kivy 桩，不需要真机/模拟器）
python -m tests.test_mobile

# 编译
buildozer -v android debug
```

**测试说明**：容器/CI 里没有 X server，SDL 的 dummy 驱动又不提供 OpenGL，
真 Kivy 起不来。所以用 `tests/fake_kivy.py` 替换渲染层，
业务逻辑代码原样运行——这与桌面版 `tests/fake_tk.py` 是同一套思路。

这套桩在开发中实际抓到了 5 个会导致真机崩溃的 bug：
回调签名参数数量不对、`Project.get_lore` 不存在、
导出时图片路径用相对路径判断（安卓 CWD 是 `/`，永远失败）、
导入列表不认 zip（带图导出后导入，列表空空如也）、
**字体写死导致启动即崩**（Kivy 找不到字体时 resolve_font_name 抛 IOError）。

最后这个最隐蔽：开发机上有字体看不出来，装到手机上才炸。
现在改成运行时探测候选字体，全都找不到就用默认字体降级——
中文可能显示成方块，但 App 不会崩，内容还能导出到桌面版继续用。
